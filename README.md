# Blobby's Adventure

**Blobby** is a 2D mobile platformer where the player navigates a character through various hazards to reach the end of each stage.


## Key Features
* **Genre:** 2D Platformer
* **Platform:** Mobile (Android / iOS)
* **Structure:** Main Menu -> 3 Playable Levels -> Win Screen


##  Gameplay & Mechanics

The goal is to navigate past all obstacles and safely reach the exit at the end of each level.

###  Health System
* The hero starts with **3 hearts (lives)**.
*  **Heart:** Restores health.

###  Hazards & Enemies
*  **Enemy:** Deals **1 damage** (removes 1 life).
*  **Rock:** Deals **1 damage** (removes 1 life).
*  **Bomb:** Deals high damage, removing **2 lives** upon impact.
